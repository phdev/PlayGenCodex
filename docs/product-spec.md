# AgentReady Product Spec (v0.1)

## Problem
SDK teams optimize docs for humans, but coding agents increasingly execute onboarding steps. Teams lack a simple way to validate if docs/CLI/testing flows are agent-consumable.

## Target users
- Developer Experience Managers
- SDK / Platform PMs
- DevRel and Documentation teams
- Developer tooling engineers

## MVP
- Deterministic trace-driven harness
- 8-dimension AX scorecard
- Friction report with causes and recommended fixes
- Before/after documentation comparison
- CI-style pass/fail output

## Non-goals
- Generic orchestration framework
- LangSmith/Braintrust competitor
- Dashboard-first SaaS

## Success criteria
- Runnable locally with no API keys
- Deterministic outputs for repeatable review
- Clear, actionable doc/tooling improvement recommendations
