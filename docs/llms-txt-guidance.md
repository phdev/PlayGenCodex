# llms.txt Guidance

Use `llms.txt` to route coding agents to canonical onboarding context.

Recommended sections:
- Primary quickstart URL/path
- API reference URL/path
- Task-specific examples
- Troubleshooting URL/path
- Explicit deprecation/"do not use" notes

For AgentReady's WidgetKit lab, `llms.txt` should prioritize docs-v2 quickstart and agent-guide over generic docs.
