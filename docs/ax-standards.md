# AX Standards for SDK Onboarding

1. **Markdown-first documentation** with predictable headings.
2. **Canonical onboarding path** in one primary quickstart.
3. **`llms.txt` routing** to the best path for coding agents.
4. **Copy/paste CLI commands** (fully qualified, no ambiguity).
5. **Expected output** after each command.
6. **Minimal working example** tied to the target task.
7. **Explicit API affordances** and anti-patterns (what *not* to call).
8. **Runnable tests** that validate expected generated artifacts.
9. **Troubleshooting linked to common failures** (missing files, invalid flags, wrong API names).
10. **Context budgeting**: concise docs that prioritize successful execution.
